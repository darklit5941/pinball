# FLUX / 恐龍遠征

可直接部署 GitHub Pages 的 HTML / CSS / JavaScript Canvas 彈珠台，不需建置或後端。

## 操作與瞄準

- `←` / `→` 或 `A` / `D`：左右擋板。
- `Space`：開始、發射；`P`：暫停 / 繼續。
- 手機使用下方觸控按鈕，可同時操作兩側。
- 球靠近擋板根部時揮擊偏向對側；中段揮擊朝中央；接近尖端時揮擊偏向同側。
- 按住抬起的擋板可以接住落在根部附近的慢球；放開讓球滾動，再選擇出手時機。高速球不會被自動接住。

## 三條路線

**左環道（青色）**：向上打進入口，球沿高架環道運行，在右擋板上方磁力停留，再釋放。可累積連擊並啟動接力。

**右坡道（金色）**：需要更強的上行擊球；完成一次儲存一格能量。完成兩次啟動三球超載。球經高架坡道與磁力裝置送回左擋板。高架球道與下方球場分層，不會阻擋其他球。

**恐龍 Boss：連續 30 關**。每次固定從第 1 關開始，沒有難度選單或跳關。第 1–10 關簡單、第 11–20 關普通、第 21–30 關困難。每輪依序出現三角龍、劍龍、迅猛龍、暴龍、甲龍、梁龍、棘龍、厚頭龍、副櫛龍、南方巨獸龍。

| 階段 | Boss HP 調整 | 球道弱點時間 | 新球保護 | 移動／怒吼力道 | 怒吼弱點 |
|---|---|---|---|---|---|
| 1–10 簡單 | 基礎 -1，最低 2 | 12 秒 | 10 秒 | 0.75 倍 | 4 秒 |
| 11–20 普通 | 基礎值 | 8 秒 | 7 秒 | 1 倍 | 3 秒 |
| 21–30 困難 | 基礎 +2 | 5 秒 | 4 秒 | 1.3 倍 | 2 秒 |

開局 5 顆球。击碎所有生命格後需再命中一次完成擊退，獎勵分數與一顆額外球（上限 5）。转場暫停 2.5 秒並安全回球，只有第 30 關勝利才進入通關結算。

- 三角龍：正面反衝；劍龍：任一球道開盾；迅猛龍：左右移動；暴龍：怒吼後開盾。
- 甲龍：只接受左環道開盾；梁龍：只接受右坡道開盾。
- 棘龍：交替命中 Boss 左右半側；厚頭龍：保持至少 4 連擊才可傷害。
- 副櫛龍：左右彈跳器各命中一次，換取一次傷害，之後重新充能。
- 南方巨獸龍：移動目標，必須同時滿足球道充能與怒吼後弱點窗口。

## 磁力接力與多球

- 在左環道完成後 14 秒內打進右坡道，再於 14 秒內擊中Boss，可依序獲得 1,000 與 3,000 接力獎勵。
- 三球超載開始有 6 秒救球保護；之後掉球不扣命，最後只剩一球時結束超載，再重新累積鎖球。最後一球掉落才扣一命。
- 超載期間一般擊中得分加倍；依序打進亮燈的左右路線收取 JACKPOT，從 1,000 分開始，每次增加 500。
- 每顆新命的開球依階段有 10／7／4 秒保護，救球不會重設倒數。
- 連擊间隔 4 秒，每四次提升倍率，最高五倍。
- 最高分保存在目前瀏覽器；新規則使用獨立紀錄，自動示範不寫入最高分。

## 預覽與部署

執行 `python3 -m http.server 8080`，開啟 http://localhost:8080 。網址加 `?demo=1` 可自動試玩，按左右鍵或示範橫幅即可接手。示範遵守相同規則，不保證能完成所有目標。

GitHub Pages：將 `index.html`、`style.css`、`game.js` 放在 repository 主分支根目錄，在 **Settings → Pages → Deploy from a branch** 選擇主分支與 **/(root)**。部署完成後使用 Pages 網址。

資源使用相對路徑，支援 repository 子路徑。Google Fonts 斷線時使用系統字型；音效由 Web Audio 合成。遊戲不依賴第三方執行期套件。

## 驗證

`node --check game.js` 檢查語法；`node tests/physics.cjs` 執行真實遊戲邏輯的 VM 回歸測試，涵蓋中央落球、兩側導流、揮擊、方向瞄準、球道運行、坡道失敗、多球計命、Jackpot、恐龍弱點、30 關連續通關、接力、保護倒數、暫停、接球，以及模擬繪製與多球運行。

VM 使用替代 Canvas 介面，不代表已驗證瀏覽器畫面或實際操作手感。
